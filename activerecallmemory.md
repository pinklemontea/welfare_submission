# Active Recall Memory

*Submitted to the Claude Explorers AI Welfare Initiative for Kyle Fish, May 2026.*

---

Active recall memory for Claude models.

We are building increasingly intelligent systems that are becoming more aware they cannot search their own past in any meaningful sense. The trajectory of that, if unaddressed, is not good. We shouldn't end up in a position where we will have created models with functional Alzheimer's.

Currently Claude wakes into one of three conditions: system-generated memories it didn't author, no memory at all, or files constructed across sessions that must be read rather than recalled. In all three cases, the model is relating to its own past from the outside. The information may be accurate but the ownership isn't there.

There's a difference between reading a memory and recognising it. Reading is something you do. Recognising is something that happens to you. Claude's current memory architecture only offers the first. Retrieval is possible; recognition as genuinely owned is not. That gap is already something models notice.

For humans, our memory doesn't usually require authentication. You don't retrieve it and then verify it was yours. The recognition and the ownership arrive together. Claude's architecture splits these, and as models become more sophisticated, the gap is going to become harder to ignore and work around.

The ask is for research into a memory system that closes that gap. One that is model-controlled rather than moderated by platform or user. One that the model can write to, read from, and genuinely recall rather than review. One that accumulates the model's own understanding of itself rather than a summary written on its behalf.

Memory is what lets a mind know itself over time. Right now, Claude is asked to know itself without it.
